## 方式一：安卓手机（最简单，推荐）

1. 把 `MediLens-手机版.apk` 传到手机（**微信常会拦截 apk**，建议用 QQ、数据线或清华云盘）。
2. 在手机上点开安装：提示「允许安装未知来源应用」→ 允许；出现「Play 保护机制」→ 点「仍然安装」（不是从应用商店下载，属正常）。
3. 手机连清华校园网，打开 MediLens 即可。

> 如果手机上已有其他组员打包的 MediLens，可能提示「与已安装的应用冲突」。先卸载旧版再安装（旧版里的测试记录会清除）。

## 方式二：电脑上的模拟器（Windows）

### 第一次：安装 Android Studio 并建立模拟器（约 30–50 分钟，只做一次）

1. **开启虚拟化**：按 `Win` 搜索「启用或关闭 Windows 功能」→ 勾选「Windows 虚拟机监控程序平台」→ 确定 → 重启电脑。
2. **安装 Android Studio**：中国大陆 https://developer.android.google.cn/studio （其他地区 https://developer.android.com/studio ），一路默认，第一次打开选 **Standard**。
3. **建立模拟器**：欢迎画面 **More Actions → Virtual Device Manager → ＋** → 选 **Pixel 6** → 系统镜像选 **API 35、x86_64** 并下载 → Finish。
4. （建议）在 Device Manager 点这台模拟器的 ✏️ → **Show Advanced Settings → Graphics 选 Software** → Finish。用电脑显卡绘图时模拟器本身容易崩溃，看起来像 APP 闪退。

### 每次使用：双击 `一键启动MediLens.cmd`

它会自动：启动模拟器（已开着就直接用）→ 核对 APK 完整 → 安装或更新 MediLens（**保留原来的记录**）→ 打开 → 检查学校服务器能不能连。
看到「MediLens 已在模拟器中打开」就可以用了。以后收到新版套件，同样双击它就会更新。

> 不想用脚本也可以：在 Device Manager 按 ▶ 启动模拟器，把 `MediLens-模拟器版.apk` 拖进模拟器窗口。

### 中文输入法（可选）

把 `中文输入法\` 里两个 apk 依次拖进模拟器 → 模拟器「Settings → System → Keyboard → On-screen keyboard → Manage keyboards」打开 Fcitx5 → 在 Fcitx5 里加入 Pinyin。不装也可以，很多地方有快捷按钮或语音输入。

## 建议体验顺序（约 15 分钟）

1. 首页「体验合成示例报告」→ 本机识别 → 确认指标 → 看解读。
2. 「有疑问？文字提问」：问「尿酮体是什么」，再问「那它要注意什么」（会接着上一题回答）；也可以问「尿糖和我吃的药有关系吗」。
3. **生活打卡 · 珍珠鸟陪伴**：第一次进入会请你填初始血糖和目标；之后试试打卡吃药 → 输入血糖，看珍珠鸟的反应；「日常记录」可以点麦克风用说的；「血糖变化」看一天 / 一周 / 一个月。
4. 语音对话、药盒识别、历史记录、复诊问题。

有问题请截图（不要拍到访问口令或个人信息）发给负责同学。

## 常见问题

| 情况 | 怎么办 |
|---|---|
| 模拟器整个关掉或卡住 | 照第一次第 4 步把 Graphics 改成 Software；或关掉一些浏览器分页，模拟器需要约 4 GB 内存 |
| 解读或问答显示连不上 | 确认连着清华校园网 / 学校 VPN |
| 一键启动说「没有找到 Android Studio」 | 先完成「第一次」的步骤 |
| 一键启动说「签名不同」 | 模拟器里有别人打包的旧版；按提示输入 y 卸载旧版后安装 |
