# MediLens

面向糖尿病患者的尿常规 / UACR 报告智能解读 APP（课程项目，MVP 2.0「项目可运行」开发中）。

> ⚠️ 本项目处于内部开发阶段：所有判读规则均为**测试规则，未经医学审核**，仅使用**合成报告**测试，不得用于真实患者诊疗。
