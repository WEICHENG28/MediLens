# 知识库填写指南（给找资料的组员）

## 要做什么

用 **`docs/知识库填写范本.xlsx`** 填写知识条目，每一行是一条知识。填好后交给开发同学导入，APP 的「详细了解」和「提问」就会使用这些内容并显示来源。

知识条目**只用于解释**（是什么、为什么异常、干扰因素、复诊该问什么），**不用于判定风险**——红黄绿判定由规则负责。

## 怎么填

打开范本的「知识条目」工作表，从第 4 行开始填（第 2、3 行是灰色示例，可保留，导入时会自动跳过）。

| 栏位 | 怎么填 | 例子 |
|---|---|---|
| 编号 | `kb-指标-序号`，不可重复 | kb-uacr-001 |
| 适用指标 | 指标代码，多个用逗号分隔；不针对指标填「通用」 | UACR,LEU |
| 标题 | 这条知识讲什么 | 感染为什么会影响 UACR |
| 内容 | 用通俗中文**改写**，约 50–200 字 | （按原意改写，不要整段复制） |
| 关键词 | 患者可能的说法，逗号分隔 | 尿路感染,发烧 |
| 来源名称 | 指南、教材或网站名称 | 《中国糖尿病肾脏病防治指南（2021年版）》 |
| 版本或年份 | | 2021 |
| 页码或段落 | 建议填写，方便查证 | 第3章 3.2节 |
| 原文链接 | 网址或 DOI（选填） | |
| 授权情况 | 下拉选择 | 仅摘要引用 |
| 审核状态 | 下拉选择；医学背景人员审核后才改「已审核」 | 未审核 |
| 审核人 | 已审核时必填 | |

**指标代码**：GLU 尿糖、KET 尿酮体、PRO 尿蛋白、LEU 白细胞、NIT 亚硝酸盐、BLD 隐血、SG 比重、PH 酸碱度、UACR 尿白蛋白/肌酐比。

## 不要写

- 诊断结论（如「您得了糖尿病肾病」）
- 停药、换药、调整剂量的建议
- 没有可靠来源的内容、整段复制的原文

## 建议的覆盖范围（首期）

9 个指标 ×（是什么 / 为什么会异常 / 有哪些干扰因素 / 复诊可以问什么），约 40 条起步。资料来源建议见 `docs/知识库资料调研.md`。

## 导入（开发同学操作）

```powershell
backend\.venv\Scripts\python tools\kb_import.py 填好的文件.xlsx --check   # 只检查
backend\.venv\Scripts\python tools\kb_import.py 填好的文件.xlsx           # 检查并导入
```

工具会逐行列出错误（如漏填、编号重复、指标代码错误、内容含诊断或用药建议），有错误时不会导入。导入后重新启动后端即生效；导入的正式知识优先于现有的占位知识。
