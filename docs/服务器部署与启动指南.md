# 服务器部署与启动指南（学校 AIOP 平台）

> 服务器：AIOP 平台虚拟机 **Ubuntu01**（Ubuntu 22.04，Python 3.10），校内地址 **101.6.162.67**，有效期至 2028-01-31。
> 后端安装在服务器的 `~/medilens`，端口 8000。**访问口令与大模型密钥只在服务器的 `~/medilens/.env`，不写进任何文件或群聊。**

## 一、每次开机怎么启动

1. 登录 AIOP 平台：http://101.6.160.93:30070/ （校园卡号登录）。
2. 状态是「关机」→ 按 ⏻ 开机，等约 5 秒 → 按 🖥 连进桌面。
3. 输入系统密码解锁。
4. **后端会在开机约 20 秒后自动启动**（已设定开机自启），一般不用做任何事。

确认有没有在运行：在电脑浏览器打开 http://101.6.162.67:8000/api/v1/health ，看到 `"status":"ok"` 就是正常。

> 开机自启已设定（crontab），但**尚未实际关机重开验证过**；第一次重开后请用上面的网址确认一次。

## 二、常用操作（在服务器终端执行）

在桌面空白处按右键 →「Open in Terminal」打开终端。

| 要做什么 | 输入 |
|---|---|
| 手动启动 / 重新启动后端 | `bash ~/medilens/scripts/server-run.sh` |
| 更新到最新版 | `bash ~/medilens/scripts/server-setup.sh` |
| 看最近的日志 | `tail -n 30 ~/medilens-backend.log` |
| 填写或修改大模型密钥、访问口令 | `nano ~/medilens/.env`，改完按 `Ctrl+O` 存档、`Ctrl+X` 离开，再执行「重新启动」 |

`.env` 里两个重要设定：
- `COMPAT_API_KEY=` 学校大模型平台的密钥（留空时自动改用不调用大模型的模式，判读与解释照常可用）；
- `API_TOKEN=` 访问口令，APP「设置 → 访问口令」要填同一组。改了口令，所有人的 APP 都要跟着改。

## 三、APP 怎么连

- 组员套件里的 APK 已**预设好服务器地址和访问口令**，装好即可用。
- 旧版 APK：到「设置 → 解读服务地址」填 `http://101.6.162.67:8000`，「设置 → 访问口令」填服务器的口令（向负责同学要）。
- **手机或电脑需要在校园网内**（101.6.162.67 是校内地址）。校外使用需连学校 VPN。

## 四、部署是怎么做的（技术说明）

- 服务器连不上 GitHub（DNS 被污染），所以部署脚本 `scripts/server-setup.sh` 依次尝试：GitHub → **jsDelivr**（国内可用的 CDN，提供 GitHub 公开仓库的文件）。只下载后端需要的文件。
- 系统缺少 `python3-venv`，又没有 sudo 权限：脚本建立不含 pip 的虚拟环境，再从**阿里云镜像**下载最新 pip 安装；依赖也从阿里云镜像安装（失败时改用清华镜像）。
- 开机自启：`crontab` 的 `@reboot`，开机 20 秒后执行 `scripts/server-run.sh`。
- 安全：后端设了访问口令（`API_TOKEN`），没有口令的请求一律拒绝（健康检查除外），避免同网段的人用掉大模型额度。
- 平台的网页远程桌面不能粘贴，也传不了 Shift/Ctrl（无法输入大写与 `: $ | @` 等符号），首次部署的命令因此全部用小写拼出。

## 五、安全提醒

- 平台说明文件里的系统预设密码大家都一样，**请改掉服务器的登录密码**（终端输入 `passwd`）。
- 桌面上的 `password.txt` 是平台原有文件，不要把我们的密钥或口令写进去。
- 不要把 `.env` 的内容截图分享。
