# MediLens MVP 2.0 测试与课堂演示指南

> 适用：本仓库开发电脑（已装好工具链与模拟器）。所有报告均为**合成数据**，判读规则为**测试规则，未经医学审核**。

## 一、一键启动（每次测试/演示前）

在仓库根目录 `D:\MediLens` 打开 PowerShell，执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\start_demo.ps1
```

脚本会依次：启动后端（**背景运行，没有单独窗口**，记录写入 `backend\backend.log`；启动失败会直接显示原因）→ 启动模拟器 → 安装 APP → 打开 MediLens。看到「已在模拟器中打开 MediLens」即可。演示结束后可不管后端（重启电脑即关闭），或执行脚本最后显示的 `taskkill` 指令。

- 修改过代码后加 `-Rebuild` 重新构建：`... start_demo.ps1 -Rebuild`
- 首次启动模拟器约 1 分钟；建议**上课前 10 分钟**先跑一次
- 关闭其他大型程序（浏览器多标签页、游戏等），电脑内存 16GB，模拟器约占 3GB

## 二、自动化测试（约 5 分钟，确认「全部通过」）

先执行一键启动（后端与模拟器需在运行），然后：

```powershell
. .\scripts\dev-env.ps1
cd backend; .\.venv\Scripts\python -m pytest -q; cd ..                       # 预期：82 passed
cd app
flutter test                                                                  # 预期：All tests passed!（22 项）
flutter test integration_test/ocr_device_test.dart -d emulator-5554           # 预期：All tests passed!（端侧 OCR 5 份报告）
flutter test integration_test/app_flow_test.dart -d emulator-5554             # 预期：All tests passed!（普通+老年模式全流程）
cd ..
backend\.venv\Scripts\python tools\eval\eval_rules.py                     # 预期：输出对照实验 A 结果（与 docs/MVP2_测试结果.md 一致）
python tools/check_network.py                                                  # 预期：✓ 未发现境外服务依赖或未登记域名
```

> 注意：集成测试会把模拟器里的 APP 替换成测试版本。跑完自动化测试后，**再执行一次一键启动**恢复正常 APP 再做手动测试/演示。

## 四、课堂演示建议路线（约 6 分钟）

### 演示前准备（上课前 10 分钟）

1. 执行一键启动：`powershell -ExecutionPolicy Bypass -File scripts\start_demo.ps1`
2. 模拟器中：「设置」→「删除本机全部记录」（避免旧记录触发趋势提示）；确认「老年模式」为**关闭**
3. 确认模拟器已能输入中文（本机已安装测试用输入法 fcitx5：空格键旁地球图标切换拼音/注音；也可直接用电脑键盘打拼音）
4. 若模拟器窗口跑到屏幕外：`powershell -ExecutionPolicy Bypass -File scriptsit_emulator_window.ps1`
5. 准备好投影 `docs/MVP2_测试结果.md`（讲数据时用）

### 演示流程

1. **定位**（30 秒）：面向糖尿病患者的尿常规/UACR 报告解读；拍照为主、本机识别、不替代医生。
2. **识别与局部确认**（1.5 分钟）：A2–A7，合成示例选「尿蛋白被遮挡」，重点展示「原图红框 + 候选点选」，强调只需确认 1 项、不用手填整张报告。
3. **安全优先**（1 分钟）：返回首页，合成示例选「尿糖+尿酮体阳性」→ 红色「请优先注意」置顶；强调「测试规则，未经医学审核」与「未知不变绿」。
4. **主动引导与分层解释**（1.5 分钟）：选择题选「是，我知道药名」→ 总览多出「SGLT2 用药影响」提示；「详细了解」原位展开；提问页输入「我这个酮体 2+ 严不严重？」→ 大模型在规则与知识约束下口语化回答；再输入「我能停藥嗎」→ 安全提示（繁体也能拦截，且不经过大模型）。
5. **老年模式与数据**（30 秒）：设置切换老年模式（字体按钮变大、功能相同）；保存到本机 → 历史记录。
6. **用数据说话**（1 分钟，投影测试结果）：
   - 局部确认：用约 11.5% 的确认工作量，把进入判读的识别错误从 3.9% 降到 0.39%
   - 对照通用逐项解读：有项目无法确认时，通用做法 8.5% 误报「全部正常」，MediLens 为 0
   - 端到端 3.3–8.0 秒（目标 ≤15 秒）
   - 如实说明未达标项：字段识别 93.8%（目标 95%）、越界提问拦截 59.1% → 下一步用语义意图分类
7. **待实现与下一步**（30 秒）：语音、药盒、注册与云备份、趋势、提醒入口均已保留；需要老师提供真实脱敏报告与医学审核。

讲解要点：可运行（Android 模拟器端到端测试通过）、隐私（原图不上传）、国内网络（无 Google/境外服务）、医学安全（规则判读与大模型分离、测试规则明确标注）、**结论均有实测数据支撑且如实报告不足**。

## 五、常见问题

| 问题 | 处理 |
|---|---|
| 「查看解读」提示无法连接 | ① 后端没有运行：浏览器打开 http://127.0.0.1:8000/api/v1/health，打不开就执行 `python scripts\run_backend.py`（需 Python 3.10 以上）；② APP 装在**真机**上：默认地址 10.0.2.2 只在模拟器内有效，需在「设置 → 解读服务地址」改为电脑的局域网地址（如 http://192.168.1.5:8000），手机与电脑连同一 Wi-Fi，并允许 Windows 防火墙放行 8000 端口；③ 交付包不含开发工具链，组员电脑上一键启动脚本无法直接使用，需先按 README 安装 Flutter 与 Android SDK |
| 模拟器窗口跑到屏幕外/只显示一半 | 执行 `powershell -ExecutionPolicy Bypass -File scripts\fit_emulator_window.ps1`，窗口会移到屏幕右侧并缩放到合适大小（一键启动已自动执行） |
| 模拟器黑屏/很卡 | 关闭其他程序；在模拟器窗口关闭后重新执行一键启动 |
| 脚本提示「无法加载，因为在此系统上禁止运行脚本」 | 使用文中的 `powershell -ExecutionPolicy Bypass -File ...` 写法 |
| APP 是测试版本/界面异常 | 跑过集成测试后需重新执行一键启动 |
| 组员想在自己电脑运行 | 需安装 Python 3.11、Flutter 3.47.8、JDK 17、Android SDK 与模拟器（见 README），约需下载 5GB；课堂演示建议统一用本机 |
| 组员想装到自己的安卓手机 | 手机与本机连同一 Wi-Fi，并放行 Windows 防火墙 8000 端口；用 `flutter build apk --debug --dart-define=API_BASE_URL=http://<本机局域网IP>:8000` 构建后安装 |
