# 第三步：本机固定时间提醒

本轮范围：Android 本机用药时间通知，接入现有生活打卡计划。复查日期、任务完成回执、稍后提醒及自适应时段尚未实现。

## 用户可用的功能

- 设置 → 本机任务提醒；生活打卡中也有入口。
- 在生活打卡中按医嘱添加时间，再主动开启通知。默认关闭；仅添加时间不会自动发送。
- 开启后按本机时间每天安排，原有计划增加、删除时同步；同一任务同一时间不重复添加，最多 32 项。
- Android 通知权限由用户决定；页面可查看权限、打开系统设置，并发送一条约 10 秒后的测试通知。
- 精确定时权限未允许时使用系统允许的非精确定时，页面说明可能延后。省电限制、关机或系统强制停止也可能影响送达；不能保证所有手机均准点。
- 重启、升级安装、系统时间/时区改变后恢复安排。系统权限被撤销后请重新打开 APP 检查和同步。
- 点击通知打开 APP；本轮不通过通知直接标记用药已完成。
- 关闭提醒、删除用药时间或删除本机全部记录时撤销相应定时任务。
- 载入演示数据前关闭提醒，避免将模拟任务当成真实用药通知。

## 隐私与网络

通知只显示“您设置的一项任务到时间了”等通用文字；药名、血糖和报告不进入通知。通知设为私密可见性。

任务类型和标签仍保存在本机加密数据库；Android 定时所需的本机配置只保存不透明 ID、时分和开关，不保存姓名、模型密钥或医疗文字。

提醒模块只调用 Android 系统，不访问服务器、不使用 Google 推送、不新增第三方依赖。时间由用户确认，不采用模型建议自动调整医嘱时间。

## 已验证

| 场景 | 结果 |
|---|---|
| 客户端测试 | 全部 46 项通过，含本轮 8 项提醒测试 |
| Flutter 静态检查 | 无问题 |
| Android ARM64 profile 编译与覆盖安装 | 成功，保留原有设置和记录 |
| 拒绝通知权限 | 页面明确显示测试未安排，没有误报开启 |
| 允许通知及精确定时 | 系统入口正常，返回 APP 自动刷新实际状态 |
| 测试通知与点击 | 模拟器通知栏收到通用文字，点击能打开 APP |
| APP 退到后台后定时送达 | 点击测试后立即回桌面，约 10.5 秒观察到本应用测试通知 |
| 保存计划 | 临时 23:59 计划显示已同步 1 项，系统存在对应闹钟 |
| 重启恢复 | 实际重启模拟器；尚未打开 APP 时，系统已恢复相同 ID/时间的闹钟 |
| 删除撤销 | 删除临时计划后原生计划列表为空，活动系统闹钟为 0 |
| 结束清理 | 临时用药时间已删除，提醒开关已关闭；原打卡记录保留 |

重启测试没有等待 23:59 的每日提醒触发；实际触发验证使用测试通知。时间/时区变更和多品牌真机省电行为尚未实测，不据此声称全部设备已通过。
