# 外部网络请求清单与中国大陆网络测试方案

> 版本：MVP 2.0（2026-10-24）。区分「用户运行时」与「开发环境」。可用 `python tools/check_network.py --apk <apk>` 自动检查源码与安装包。

## 1. APP 运行时网络请求（用户手机发出）

| # | 目标 | 用途 | 发送内容 | 何时发生 | 失败时降级 |
|---|---|---|---|---|---|
| 1 | MediLens 后端（开发期 `http://10.0.2.2:8000`；正式部署为中国大陆云服务器 HTTPS 域名，待定） | 规则判读、选择题、详细了解、文字对话 | 用户确认后的结构化指标（项目名/结果/单位/参考范围/检验日期）、选择题回答、对话文字；**不含图片、姓名、医院** | 用户在 P03 点「查看解读」并同意后 | 提示「无法连接解读服务，请检查网络后重试」；已识别指标保留在本机，可重试；不显示伪造结果 |

**APP 不直接访问任何第三方服务**：

- 本地 OCR 模型随安装包打包（`app/assets/ocr/`），运行时不下载。
- 朗读使用手机系统 TTS 引擎（离线）。
- 不使用 Google Play 服务、Firebase/FCM、Google 登录、Google Analytics、Google Fonts、境外 CDN；字体使用系统字体。
- 不使用任何统计/崩溃上报 SDK。

| 2 | `{WorkspaceId}.cn-beijing.maas.aliyuncs.com` | 通义千问（阿里云百炼） | 同上 | `LLM_PROVIDER=qwen` | 同上 |

## 3. 开发环境网络（不影响用户）

| 用途 | 地址 |
|---|---|
| Flutter SDK 与引擎产物 | `storage.flutter-io.cn`（国内镜像） |
| Dart 包 | `pub.flutter-io.cn`（国内镜像） |
| Python 包 | `mirrors.aliyun.com/pypi`（国内镜像） |
| Android SDK / NDK / 模拟器镜像 | `dl.google.com`（sdkmanager） |
| Gradle 与 Maven 依赖（含 ONNX Runtime、SQLCipher 的 Android 库） | `services.gradle.org`、`dl.google.com`（Google Maven）、`repo.maven.apache.org` |
| Docker 基础镜像（未实测） | Docker Hub；国内可配置阿里云容器镜像加速 |

说明：开发者构建 APK 时下载的依赖会被编译进安装包，用户运行时不再访问这些地址。若开发者在大陆网络下 Gradle 下载缓慢，可在 `android/settings.gradle.kts` 中添加阿里云 Maven 镜像（`maven.aliyun.com/repository/google`、`/public`），属于开发环境配置。

## 4. 已执行的检查

- `tools/check_network.py`：扫描 `app/lib`、Android/iOS 工程、`backend/app` 中的全部 URL，与允许清单比对，并检查禁止项（googleapis、firebase、openai、jsdelivr、unpkg、fonts.google 等）。结果见 `docs/开发进展.md`。
- APK 检查：扫描 dex 是否包含 `com/google/android/gms`、`com/google/firebase` 等类。
- 模拟器使用**不含 Google 服务的 AOSP 系统镜像**（Android 15），与多数国内手机一致；APP 在该镜像上可运行即说明不依赖 Google Play 服务。

**尚未执行**：在中国大陆真实网络环境中的实机测试（开发机网络环境不是大陆普通网络，不能据此声称已通过）。

## 5. 中国大陆网络测试方案（待执行）

**前提**：后端部署到阿里云/腾讯云大陆地域（HTTPS + ICP 备案域名），APP 构建时 `--dart-define=API_BASE_URL=https://<正式域名>`。

| 编号 | 场景 | 步骤 | 通过标准 |
|---|---|---|---|
| N1 | 无 VPN 普通网络 | 大陆家庭宽带 Wi-Fi、移动/联通/电信 4G/5G 各一次，关闭一切代理，走完游客全流程 | 全流程可完成；P04 解读响应 < 5 秒（mock）/ < 15 秒（真实模型） |
| N2 | 抓包核对 | 手机配置抓包代理（如 Charles/mitmproxy，仅测试机），走完全流程 | 只出现 MediLens 后端域名；**请求体中无图片数据**；无 Google/境外域名 |
| N3 | 断网 | 识别完成后开启飞行模式，点「查看解读」 | 显示无法连接提示，已识别结果仍在，不崩溃；恢复网络后可重试 |
| N4 | 弱网 | 使用网络限速（如 Android 开发者选项或路由器限速 50kbps / 高延迟） | 25 秒超时提示，可重试；无重复提交 |
| N5 | 模型服务失败 | 后端填写错误密钥或断开外网 | 对话返回标准说明并标注；规则判读与紧急提示不受影响 |
| N6 | 无 Google 服务手机 | 华为（HarmonyOS/EMUI）、小米、OPPO、vivo 各一台 | 安装、启动、拍照、相册、PDF、朗读均可用 |
| N7 | 系统朗读 | 上述手机测试「朗读」 | 有中文语音；无中文引擎时有提示 |

测试记录按交接说明 9.3 格式填写：需求编号、设备、网络、输入样本、预期、实测、截图/日志、已知问题。
