# MVP3 规划：糖尿病贴身照护助理

> 制定日期：2026-11-17。依据：老师建议文件《融合医院检验与居家多源时序数据，研究其对血糖异常情境识别、风险提示及管理行动建议品质的增量价值》（下称「老师文件」）。
> 状态：**第 1–6 步已完成**（2026-11-18），第 7 步只做中式食物辨识微调；完成情况见 [开发进展](开发进展.md) 迭代 21，组员说明见 [MVP3_照护助理说明与演示](MVP3_照护助理说明与演示.md)。

## 一、定位

融合**医院检验**与**居家多模态资料**（照片、语音、数值），每一笔新资料都放进患者的**整体状况**里解读；有证据才下结论、持续监测，并陪患者验证每一个改善——像一位贴身护士。

老师文件的研究问题：在医院检验基础上逐层加入居家血糖、饮食、活动等资料，能否提高**异常情境识别、风险提示、行动建议**的品质；重点不是资料越多越好，而是每多一类资料带来**可说明、可验证的增量**。

与现有 APP 的关系：沿用「规则与统计负责判断、大模型只负责表达、输出经安全校验」的架构；尿检解读与生活打卡从「各做各的」升级为共用同一份照护档案。

## 二、系统流程

```
【输入：多模态】
报告照片（OCR）· 餐点照片（食物识别＋份量可修正）· 语音（「我刚吃了一碗面」）
血糖（指血 / 血糖仪）· 用药打卡 · 散步 · 睡眠 · 血压 · 体重
        ↓ 每笔记录按下即存（手机本机）
【① 统一时间轴】所有资料按时间排列
        ↓
【② 照护档案（每次由全部记录重新计算，可复现）】
  背景：病史、用药与服药时间、医生定的目标范围、最新检验
  个人反应：吃什么、何时吃 → 血糖怎么变
  观察中的推测：附「符合 / 不符合」证据次数
  今天的状况：已吃、已测、已用药、活动
  改善计划：当前一个小目标及其成效
        ↓
【③ 判断（规则＋统计）】
  即时：这笔资料在整体脉络下的意义、安全提示、下一步提醒
  累积：重复出现才把推测升级为「关联」
  综合：医院检验 × 居家资料（例：HbA1c 偏高＋夜间低值 → 不可自行加药）
        ↓
【④ 输出】大模型转为温和白话 → 安全校验 → 呈现
  即时回应 · 安全提示卡 · 每日小结 · 图表 · 改善建议 · 周报 · 复诊摘要 · 问答
```

### 三层分析（为什么不是「一笔资料就下结论」）

| 层级 | 何时运行 | 输出 | 例子 |
|---|---|---|---|
| 即时回馈 | 每记一笔 | 这一笔在个人脉络中的意义、安全提示、下一步提醒 | 拍晚餐：「碳水约 85 g，比你平常晚餐多；今天比平常晚 70 分钟，药是照平常时间吃的吗？20:30 提醒你测餐后血糖」 |
| 每日小结 | 睡前或打开时 | 今天记了什么、漏了什么、今晚注意事项 | 「4/5 次血糖在范围内，晚餐后 12.8 偏高；今晚睡前测一次」 |
| 规律分析 | 每有新资料就重算，**证据够才显示** | 规律与三级结论；不够时显示进度 | 「晚吃的夜里已记录 2 次，再 2 次就能判断」 |

### 结论分级（老师文件要求「区分事实、重复关联、待核实问题」）

1. **事实**：例：晚餐后 2 小时中位数 12.1，高于早餐 9.0、午餐 9.7。
2. **多次出现的关联**：只写「相关」，不写「导致」；附次数。
3. **待问医生**：用药、剂量、服药时间一律归入此类。
4. **仍然不能判断**：例：只有医院报告时，「无法判断何时偏高、有无夜间低值」。

## 三、患者的一天

| 时间 | 患者做什么 | 系统回应 |
|---|---|---|
| 起床 | 测空腹血糖 | 与他自己的常见范围比较；提醒早上的药 |
| 三餐 | 拍照或语音记录 | 估算碳水（可修正）、与平常比较、判断是否晚吃、约好 2 小时后提醒测血糖 |
| 用药 | 打卡 | 珍珠鸟陪伴；记录是否按时 |
| 餐后 | 测血糖、散步 | 对照这一餐解读，更新「个人反应」 |
| 睡前 | 看每日小结 | 今天整理、今晚注意事项、观察中的推测 |
| 异常 | — | 红色提示卡与处理步骤；该事件计入推测证据 |
| 每周 / 复诊前 | 看周报、复诊摘要 | 三级结论＋要问医生的问题 |

## 五、模拟资料规划

所有模拟资料一律标注「合成资料」，对外如实说明只在合成资料上验证。

**陈女士示范病例**按老师文件数值生成，包括：
- **血糖**：约 92% 覆盖率，TIR 58% / TAR 39% / TBR 3%。早、午、晚餐后中位数分别为 9.0 / 9.7 / 12.1。两晚低于 3.9，指血复核 3.8 / 3.7。
- **三餐**：14 天共 42 餐，含照片估算碳水。6 次高碳水晚餐中有 5 次餐后 ≥12.0。米饭估算约 200 g，家属复秤约 280 g，附修正记录。
- **晚餐时间**：两次夜间低值前，晚餐比平常晚 60–80 分钟，用药仍照平常时间。
- **用药**：二甲双胍，加一种磺脲类药物。
- **活动与睡眠**：日均约 3,800 步；4 天餐后步行 20–30 分钟；平均睡眠约 5 小时 50 分钟。
- **血压、体重**：家庭血压约 138/78；体重 66.8 → 66.5 kg。

**评测用病例**：按情境组合（晚餐后偏高、夜间低值、晚吃照常用药、饭后散步有帮助、无规律对照），并加入漏记、测量误差、份量估错、血糖仪与指血不一致等干扰。

## 六、不变的原则

- 不诊断、不调药；用药问题一律列入「问医生」；运动建议加「在医生同意下」。
- 只写「相关」，不写「导致」；单次只记录，重复才说关联。
- 判断由规则与统计负责，大模型只负责表达并经安全校验；每句话可查到依据了哪些记录。
- 照片留在手机；服务器只计算、不长期保存。
- 是否重新训练模型：判断部分不训练（没有真实病患资料，用模拟资料训练等于循环论证）。识别、表达使用现成模型。唯一建议的训练项目是第 32 项：中式食物识别微调。
- 未实测的不写「已通过」。

## 七、进行方式

1. 先写设计细节，再给组员确认，约 1–2 天。内容包括照护档案字段、推测升级门槛、即时回应规则、图表草图。
2. 第一、二阶段一起做，约 2 周。做完后能用陈女士资料在 APP 内完整走一遍日常流程。
3. 接着做第三、四阶段，再做第五阶段实验。
4. 第六阶段视时间决定。
