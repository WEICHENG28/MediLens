# 中文朗读与音色首版

2026-10-31。入口：设置 → 中文朗读与音色。先检测，再选择与试听；实时双向语音仍按后续计划实现。

## 本轮完成

- 枚举当前系统语音引擎的音色，仅接受带普通话语言标识、明确声明无需联网、未标记语音包未安装的音色。缺少离线元数据时不猜测可用性。不会自动下载或调用云端语音服务。
- 检测失败、没有可用音色时显示说明，可重新检测；试听始终使用固定示例文本，不拿真实报告测试音色。
- 音色选择保存在本机加密设置，所有原有报告/问答朗读按钮共用。每次朗读重新检测，原音色被移除时要求重新选择，不静默更换后播放报告。
- 全局单一朗读会话，切换按钮会先停止旧声音；完成、取消、系统异步错误和拒绝播放会复原按钮。检测/调用有超时保护；检测期间点击停止会阻止随后播放。
- 朗读按钮离开页面、页面被新路由覆盖或 APP 进入后台时请求停止；试听页退出与进入后台同样停止。
- 依照本机 flutter_tts 4.2.5 的 README 和 Android 源码补齐 Android 11+ 的 TTS 服务可见性声明，使用真实音色属性，不臆测男女声或音质。
- 原“自动朗读解释”开关此前仅保存偏好，没有触发播放。本轮将其明确标记待完善，保留旧设置字段、不自动播放，避免误导。语速设置保留。

## 国内与离线边界

APP 本轮不依赖境外语音 API、不内置 Google 云端服务，也不自动跳往境外下载页面。但 APP 尚未捆绑离线普通话引擎；有声朗读依赖手机预装或用户安装的系统中文语音包。仅凭引擎元数据不能保证第三方引擎实际行为或厂商音质，国内多品牌手机、断网发声和省电策略仍需实测。没有语音时文字阅读继续可用，不影响本地识别和历史记录。
