# MediLens 组员安装与使用指南（模拟器 / Android 手机）

> **2026-10-28 起，APP 直接连接学校服务器**：组员**不需要再安装 Python、也不需要启动后端**。
> 条件：电脑或手机要在**清华校园网**内（校外请先连学校 VPN）。
> 所有报告均为合成数据；判读规则为测试规则，未经医学审核。

## 组员套件内容

| 文件 | 用途 |
|---|---|
| `MediLens-模拟器版.apk` | 电脑上的 Android 模拟器用 |

| 本指南 | |

两个 APK 都已**预设好服务器地址与访问口令**，装好就能用。访问口令只在小组内使用，**不要把 APK 公开发到网上**。

## 方式一：Android 手机（最简单）

1. 把 `MediLens-真机版.apk` 传到手机（**微信常会拦截 apk**，建议用 QQ、数据线或清华云盘；约 158 MB）。
2. 在手机上点开 apk 安装：
   - 提示「是否允许安装未知来源应用」→ 允许；
   - 出现「Play 保护机制」警告 → 点「仍然安装」（因为不是从应用商店下载，属正常）。
3. 手机连**清华校园网 Wi-Fi**，打开 MediLens 即可使用。

## 方式二：电脑上的 Android 模拟器

### 第一次安装（约 30–50 分钟，只做一次）

**步骤 1：开启虚拟化**
1. 按 `Win` 键搜索「**启用或关闭 Windows 功能**」（繁体系统为「開啟或關閉 Windows 功能」）。
2. 勾选「**Windows 虚拟机监控程序平台**」（繁体为「Windows Hypervisor 平台」）→ 确定 → **重启电脑**。
3. 检查：「任务管理器 → 性能 → CPU」右下角「虚拟化」应为「已启用」。若为「已禁用」，需进 BIOS 开启 Intel VT-x / AMD-V。

**步骤 2：安装 Android Studio 并建立模拟器**
1. 下载：中国大陆 https://developer.android.google.cn/studio （其他地区 https://developer.android.com/studio ）。
2. 安装一路默认；第一次打开选 **Standard**，让它下载 Android SDK（约 1–2 GB）。
3. 欢迎画面点 **More Actions → Virtual Device Manager** → **＋** → 选 **Pixel 6** → 系统镜像选 **API 35（x86_64，Android 15）** 并下载 → Finish。
4. 点 **▶** 启动模拟器。

**步骤 3：安装 APP**
把 `MediLens-模拟器版.apk` **直接拖进模拟器窗口**，约 30 秒装好；往上滑打开应用列表，找到 **MediLens**。

**步骤 4（可选）：中文输入法**
1. 把 `中文输入法\` 里两个 apk 依次拖进模拟器（先 `org.fcitx.fcitx5.android-…`，再 `…plugin.chewing…`）。
2. 模拟器「Settings → System → Keyboard → On-screen keyboard → Manage keyboards」打开 **Fcitx5**。
3. 打开 Fcitx5 → **Input Methods** → **＋** → 加入 **Pinyin** 和 **Chewing**；打字时点地球图标切换。

不装也可以：提问页有快捷按钮。

### 每次使用（约 1 分钟）

Android Studio → Device Manager → ▶ 启动模拟器 → 打开 MediLens。**不用启动任何后端。**

## 体验流程

1. 「游客体验（无需注册）」
2. 「体验合成示例报告（演示用）」→ 选一份，例如「尿糖+尿酮体阳性」
3. 「开始识别」→ 在红框处选择正确的值（UACR 一律要核对）→「查看解读」→「同意并继续」
4. 之后可试：回答补充问题、「详细了解」（下方有文献出处）、提问（试试「这份报告整体怎么样」「呼吸好急促怎么办」）、保存、老年模式

完整的测试清单见 `docs\MVP2_测试与演示指南.md`。

## 以后 APP 怎么更新

- **判读规则、知识库、回答方式**都在服务器上：负责同学更新服务器后，**所有人立刻生效，不用重装 APP**。
- **APP 画面或识别功能**改了才需要新 APK：负责同学会发新的 apk，**直接安装覆盖即可，记录会保留**。
  若提示「与已安装的应用签名不一致」，先卸载旧版再安装（本机历史记录会被清除）。

## 常见问题

| 问题 | 原因与处理 |
|---|---|
| 「无法连接解读服务（http://101.6.162.67:8000）」 | ① 不在校园网（连校园网 Wi-Fi 或学校 VPN）；② 服务器没开机（请负责同学开机）。电脑浏览器打开 http://101.6.162.67:8000/api/v1/health 看得到 `"status":"ok"` 就表示服务器正常 |
| 「访问口令不正确」 | 装了旧版 APK：改装新版，或在「设置 → 访问口令」填负责同学给的口令 |
| 提问的回答比较制式 | 学校大模型平台偶尔超过 15 秒没回应时，会改用经核对的标准说明，属正常 |
| 模拟器无法启动 / 提示虚拟化 | 回到「步骤 1」检查虚拟化 |
| 拖入 apk 没反应 | 等模拟器完全开机后再拖 |
| 解读出现「尿蛋白等级上升」 | 历史记录中有旧报告：「设置 → 删除本机全部记录」后重试 |

## 附：校外又连不上 VPN 时（备用）

在自己电脑运行后端：解压 `MediLens_MVP2_交付包.zip` 到 `D:\MediLens`，安装 Python 3.10 以上（安装时勾选「Add python.exe to PATH」），在该文件夹执行 `python scripts\run_backend.py`；
再到 APP「设置 → 解读服务地址」改为 `http://10.0.2.2:8000`（模拟器）。本机后端不检查访问口令，口令不用改。
