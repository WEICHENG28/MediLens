# MediLens 组员电脑安装与运行指南（Android 模拟器）

> 适用：**组员自己的 Windows 电脑**，用 Android 模拟器体验 MediLens。
> 组员**不需要**安装 Flutter 等开发工具，只需要：Python（运行后端）+ Android Studio（提供模拟器）+ 组员套件。
> 所有报告均为合成数据；判读规则为测试规则，未经医学审核。

## 组员套件内容

| 文件 | 用途 |
|---|---|
| `MediLens_MVP2_交付包.zip` | 项目代码（后端在里面） |
| `MediLens-模拟器版.apk` | 已打包好的 APP，直接拖进模拟器安装 |
| `中文输入法\`（可选） | 模拟器打中文用（拼音 + 注音） |
| 本指南 | |

## 电脑要求

- Windows 10 / 11（64 位），建议内存 16 GB（最少 8 GB）
- 硬盘剩余空间约 15 GB（Android Studio 与模拟器）
- 安装期间需要联网（之后运行不需要额外下载）

## 第一次安装（约 40–60 分钟，只做一次）

### 步骤 1：解压项目代码

把 `MediLens_MVP2_交付包.zip` 解压到**路径不含中文和空格**的位置，建议 `D:\MediLens`。
解压后 `D:\MediLens` 里应直接看到 `app`、`backend`、`docs`、`scripts` 等文件夹（如果多了一层 `MediLens\MediLens`，把里面那层移出来）。

### 步骤 2：安装 Python 3.11

1. 下载 Python 3.11（任选其一）：
   - 官网：https://www.python.org/downloads/
   - 中国大陆镜像：https://mirrors.huaweicloud.com/python/3.11.9/ → 下载 `python-3.11.9-amd64.exe`
2. 安装时**务必勾选「Add python.exe to PATH」**，再点 Install Now。
3. 检查：打开 PowerShell，输入 `python --version`，应显示 `Python 3.11.x`（3.10 以上即可）。

> 已装 Anaconda 也可以，只要 `python --version` 显示 3.10 以上。

### 步骤 3：开启虚拟化（模拟器需要）

1. 按 `Win` 键搜索「**启用或关闭 Windows 功能**」（繁体系统为「開啟或關閉 Windows 功能」）。
2. 勾选「**Windows 虚拟机监控程序平台**」（繁体为「Windows Hypervisor 平台」）→ 确定 → **重启电脑**。
3. 检查：打开「任务管理器 → 性能 → CPU」，右下角「虚拟化」应为「已启用」。若为「已禁用」，需进入电脑 BIOS 开启 Intel VT-x / AMD-V（各品牌方法不同，可搜索「电脑型号 + 开启虚拟化」）。

### 步骤 4：安装 Android Studio 并建立模拟器

1. 下载 Android Studio：
   - 中国大陆：https://developer.android.google.cn/studio
   - 其他地区：https://developer.android.com/studio
2. 安装时一路默认（Next）。第一次打开会进入设置向导，选 **Standard**，让它下载 Android SDK（约 1–2 GB）。
3. 打开后在欢迎画面点 **More Actions → Virtual Device Manager**（或 Device Manager）。
4. 点 **＋（Create Virtual Device）** → 选 **Pixel 6** → Next。
5. 系统镜像选 **API 35**（x86_64，标示「Android 15」）→ 点旁边的下载图标下载（约 1.5 GB）→ Next → Finish。
6. 在设备列表点 **▶** 启动模拟器，等出现手机桌面。

> 模拟器窗口太大、跑出屏幕时：点模拟器右侧工具栏的「⋮」→ Settings → 调整，或直接拖动窗口角落缩放。

### 步骤 5：安装 MediLens APP

把 `MediLens-模拟器版.apk` **直接拖进模拟器窗口**，等约 30 秒出现安装完成提示。
在模拟器桌面往上滑打开应用列表，找到 **MediLens**。

### 步骤 6（可选）：安装中文输入法

模拟器默认只有英文键盘。需要在「提问」里打中文时：
1. 把 `中文输入法\` 里的两个 apk 依次拖进模拟器安装（先装 `org.fcitx.fcitx5.android-…`，再装 `…plugin.chewing…`）。
2. 模拟器中打开「Settings → System → Keyboard → On-screen keyboard → Manage keyboards」，打开 **Fcitx5**。
3. 打开 Fcitx5 应用 → **Input Methods** → 右下角 **＋** → 加入 **Pinyin**（拼音）和 **Chewing**（注音）。
4. 打字时点空白键旁的地球图标切换。

不装也可以：提问页有「这个指标是什么」「复诊问什么」等快捷按钮，不用打字。

## 每次使用（约 2 分钟）

**一定要按顺序：先开后端，再用 APP。** 「查看解读」需要后端，后端没开就会出现「无法连接解读服务」。

### 1. 启动后端

在 `D:\MediLens` 文件夹空白处按住 `Shift` + 右键 →「在终端中打开」（或打开 PowerShell 后输入 `cd D:\MediLens`），执行：

```powershell
python scripts\run_backend.py
```

- 第一次会自动安装依赖（约 1–2 分钟，需联网）。
- 看到「**MediLens 后端启动**」和 `Uvicorn running on http://0.0.0.0:8000` 就表示成功。
- 如果 Windows 防火墙询问是否允许 Python 访问网络，点「允许」。
- **这个窗口在使用期间不要关闭**。

检查：用电脑浏览器打开 http://127.0.0.1:8000/api/v1/health ，看到 `{"status":"ok",...}` 即正常。

### 2. 打开模拟器与 APP

Android Studio → Device Manager → ▶ 启动模拟器 → 打开 MediLens。
（模拟器中的 APP 通过 `10.0.2.2:8000` 访问你电脑上的后端，无需设置。）

### 3. 体验流程

1. 「游客体验（无需注册）」
2. 「体验合成示例报告（演示用）」→ 选一份，例如「尿蛋白被遮挡（需确认）」
3. 「开始识别」→ 在红框处选择正确的值 →「查看解读」→「同意并继续」
4. 之后可试：回答补充问题、「详细了解」、提问、保存、历史记录、设置中的老年模式

完整的测试清单与演示路线见 `docs\MVP2_测试与演示指南.md` 第三、四节。

### 4. 结束

关闭模拟器窗口；在后端窗口按 `Ctrl + C` 后关闭。

## 常见问题

| 问题 | 原因与处理 |
|---|---|
| 「查看解读」显示「无法连接解读服务（http://10.0.2.2:8000）」 | **后端没有运行**。按「每次使用 → 1. 启动后端」执行，并用浏览器检查 health 地址 |
| 执行 `python scripts\run_backend.py` 显示「需要 Python 3.10 或以上」 | 按步骤 2 安装 Python 3.11 |
| 显示「找不到 python」或「不是内部或外部命令」 | 安装 Python 时没勾选「Add to PATH」→ 重新安装并勾选 |
| 安装依赖时网络错误 | 检查网络；或设置其他镜像后重试：`$env:PIP_INDEX_URL="https://pypi.tuna.tsinghua.edu.cn/simple"; python scripts\run_backend.py --install` |
| 显示端口 8000 被占用 | 换端口：`python scripts\run_backend.py --port 8001`，再到 APP「设置 → 开发调试 → 解读服务地址」改为 `http://10.0.2.2:8001` |
| 模拟器无法启动 / 提示虚拟化 | 回到步骤 3 检查虚拟化 |
| 拖入 apk 没反应 | 等模拟器完全开机后再拖；或在 Android Studio 的 Device Manager 中重启模拟器 |
| 解读结果和指南不一样（出现「尿蛋白等级上升」） | 历史记录中有旧报告：APP「设置 → 删除本机全部记录」后重试 |

> 不要用 `scripts\start_demo.ps1`：它依赖开发电脑上的工具链（不在交付包里），只适用于项目负责人的电脑。
