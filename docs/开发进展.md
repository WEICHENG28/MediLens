## 迭代 1｜2026-10-24｜Android 模拟器 + 后端规则引擎

### 做了什么
- 开启 Windows Hypervisor 平台后，在 `.toolchain/android-sdk` 安装 SDK（platform 35/36、build-tools 35、emulator），创建模拟器 `MediLens_API35`（Android 15，**AOSP 无 Google 服务镜像**，更接近国内手机）；已实测开机，adb 可连接。`flutter doctor` 的 Android 工具链检查全部通过。
- 新增 `scripts/dev-env.ps1`：一键加载 flutter/java/adb/emulator 环境变量与国内镜像（仅开发环境）。
- 后端（FastAPI）：
  - `normalize`：同义词映射、定性分级（阴性/±/1+…4+）、UACR 单位换算（mg/mmol→mg/g，系数待审核）、参考范围比对、矛盾检测（数值不合理、单位缺失/无法识别、异常标记与范围不一致）。
  - `rules_engine` + `rules.yaml`：R-01～R-06 模拟规则，三值逻辑（缺失信息 → 「无法判断，不代表正常」），全部标注「测试规则，未经医学审核」。
  - `followup` + `questions.yaml`：7 道动态选择题，可跳过/不确定/不愿透露，服务端无状态以支持回退；危险症状回答立即升级为红色紧急提示。
  - `analysis`：总览（高风险置顶、未知不变绿、未覆盖异常项提示「无法据此判断」、缺失关键项目、复诊问题汇总）、非目标报告提示。
  - API：`/api/v1/health`、`/api/v1/analyze`、`/api/v1/followup/validate`。
- `scripts/run_backend.py` 一条命令启动；`docker-compose.yml` 与 Dockerfile（**未经实测**）。

### 没做什么
- 对话、知识检索、大模型 adapter、输出校验（下一步）。
- 尚未开始 Flutter 客户端。
