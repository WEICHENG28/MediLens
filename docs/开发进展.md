  - API：`/api/v1/health`、`/api/v1/analyze`、`/api/v1/followup/validate`。

## 迭代 2｜2026-10-24｜对话、详细了解、大模型 adapter、输出校验、待实现接口

### 做了什么
- `knowledge`：占位知识库 `kb_test.yaml`（**开发团队自编，非指南原文，未经审核**），按指标代码与关键词检索；检索不到明确返回「无法据此回答」。
- `llm`：provider adapter——mock（默认）/ DeepSeek / 通义千问 / 智谱，均为 OpenAI 兼容协议、httpx 直连，地址与模型可在 .env 配置；缺密钥自动降级 mock。接口地址于 2026-10 查阅官方文档确认。
- `guard`：输出校验——越界用药/诊断表述、与报告不一致的数值、无规则支持的紧急结论；不通过或服务失败 → 回退为基于规则与知识的草稿。
- `chat`：`/api/v1/explain`（逐条详细了解：原因、相关指标、依据、单位换算、复诊问题）、`/api/v1/chat`（快捷问题 what/related/doctor + 自由文字）；停药/换药/确诊/危险症状走安全模板（关键词 + 药名词表 × 动作词组合，结合报告上下文）。
- `pending`：语音会话、药盒识别、云 OCR、注册登录、云备份/恢复接口统一返回 501「待实现」，并列出候选国内服务；语音状态机定义 `/api/v1/voice/states`。
- `.env.example` 列出全部所需密钥。

### 没做什么
- 未接入真实大模型（无密钥）；语音、药盒、云 OCR、账号、备份仅接口占位。
- 越界意图识别目前为规则方式，后续可增加模型分类 + 规则双保险。

## 迭代 3｜2026-10-24｜合成报告、端侧 OCR、Flutter 客户端全流程、端到端测试

### 做了什么
- **合成报告**：`tools/gen_synthetic_reports.py` 生成 9 份合成报告（正常、尿糖+酮体、尿蛋白被遮挡、UACR+感染、mg/mmol、缺参考范围、肝功能、横置、模糊），图上带「合成测试样本」水印，附标注 JSON。
- **OCR 可行性验证**：`tools/ocr_reference.py`（Python + ONNX Runtime）在合成报告上验证 PP-OCRv5 识别准确（大部分字段置信度 >0.99）；导出 OCR 结果供 Dart 解析单测使用。
- **端侧 OCR（Dart）**：检测前后处理（连通域、外扩、坐标映射）、CTC 解码、自动判断横置并旋转、图像质量检查（模糊/偏暗/反光/分辨率）；报告解析（行聚类、表头定位列、合并单元格拆分、同义词映射、日期识别）；低置信（<0.95）与矛盾字段（单位缺失/无法识别、数值不合理、阴性带↑、未识别结果）进入局部确认并生成易混淆候选。
- **Flutter 客户端页面**：P01 启动（游客/注册待实现、老年模式开关）、主页（拍照/相册/文件（图片+PDF 首页）/合成示例）、P02 导入预览（质量提示、旋转、重拍）、P03 局部确认（原图高亮框、局部放大、候选、其他手动更正、无法确认、重拍、第 x/y 项）、首次解读前单独告知同意、P04 总览（紧急提示置顶、测试规则标识、计数、受缺失信息影响的结论）、P05 动态选择题（跳过/不确定/不愿透露/上一题）、P06 逐条「详细了解」原位展开 + 朗读 + 文字对话（快捷问题）、保存选择（本机加密/不保存）、P09 历史（删除单条/全部）、P10 复诊问题（复制）、P11 设置中心；P07 语音、P08 药盒、注册登录、提醒为「待实现」页。
- **本地加密存储**：SQLCipher，密钥存系统安全存储；不保存原图。
- **网络合规**：`tools/check_network.py` 扫描源码与 APK；新增 `docs/网络请求清单与大陆网络测试.md`。
- README 补全安装、启动、测试命令。

### 发现并修复的问题（均由测试发现）
- 老年模式主题放大字号时断言崩溃（基础字体无字号）→ 并入 Material 字号几何后再缩放。
- Android 9+ 默认禁止 HTTP 明文，调试版无法连接开发机后端 → 仅调试版允许明文；正式版要求 HTTPS；主清单补 INTERNET 权限。
- 检测器把相邻两列合成一个框（「mg/mmol <3.4」）→ 按空格拆分并按字符位置估算列。
- 「↑」箭头检测不稳定 → 判读不依赖箭头，只依赖参考范围比对。
- Windows 跨盘（项目 D: / 缓存 C:）Kotlin 增量编译失败 → 关闭 Kotlin 增量编译。
- NDK 未自动安装 → 手动安装 NDK 28.2。
- iOS Info.plist 补充相机/相册/麦克风权限说明。

见 README：`python scripts/run_backend.py`；`. .\scripts\dev-env.ps1; emulator -avd MediLens_API35; cd app; flutter run`

## 迭代 5｜2026-10-25｜按老师建议补实测结果与对照实验

### 做了什么
- **OCR 评测体系**：`tools/eval/gen_eval_set.py` 生成合成评测集（3 种版式 × 8 种干扰 + 非目标报告），分**开发集**（调参用）与**独立测试集**（只评测一次）；`tools/eval/run_ocr.py` 识别；`app/tool/eval_ocr.dart` 用 APP 实际解析器逐字段比对。
- **依据开发集错误分析改进解析器**：英文缩写形近字匹配（PR0→PRO）、中文名一字容错、单位形近字（mmo1→mmol）、按 OCR 规律生成候选（丢失的 +、I/l→1、逗号→小数点、丢失的小数点、无效值给完整等级）、单独的「+」一律确认、确认门槛 0.95→0.85。演示样本 03 污渍加重（使其真正难以辨认）。
- **规则评测与对照实验 A**（`tools/eval/eval_rules.py`）：1000 份随机合成报告，MediLens vs 通用逐项解读。
- **越界提问评测**（`tools/eval/eval_boundary.py`）：两轮各 60 句；拦截器改为「对象词 × 意图词」组合并结合报告上下文。
- **端到端计时**（`integration_test/perf_test.dart`）与**解释出处/数值一致性**统计。
- 新增 `docs/MVP2_测试结果.md`、`docs/企划书修改稿_MVP2.md`；重拍截图。
