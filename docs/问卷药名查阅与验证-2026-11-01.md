# 问卷中的本机药名查阅

2026-11-01。承接本机药名保存，本轮实现用户答题时主动查阅药名记录这一小步。药物分类和真实包装验证仍未完成，本轮不以自动归类或自动代答代替医学审核。

## 已实现

- 仅当当前题目带有`medication_photo_hint`时展示“答题前，查阅本机药名记录”，默认收起；用户展开后才读取本机药名记录。其他题目不展示、也不读取。
- 展示完整药名、“仅保存药名/当时确认在用”的状态，以及使用情况记录时间。记录可能已变化，提醒核对当前情况；不按时间阈值推断现在是否使用。
- 可进入本机药名记录核对或修改，返回题目后重新读取；返回、删除或修改药名均不选择答案、不改变题目、不提交网络请求。
- 没有记录时明确“不代表没有用药”；读取失败保留原数据，提供重试，同时保留原题选项、“不确定”和跳过等入口。
- 卡片仅作只读参考，不做药物分类、不推荐答案。用户仍须独立选择当前题目的选项；拿不准时可以选择“不确定”。原紧急提示和测试规则标识保留。
- 展开卡片不会发送药名；提交问卷时仍使用现有结构化报告、回答选项和报告历史，不附加本机药名、使用状态、资料出处或记录时间。

## 验证

5项新增页面测试通过：主动读取、记录时间/状态显示、查看不提交、选择不确定后的真实客户端请求体检查、无记录与大字显示、修改路由返回刷新、读取失败重试、不相关题目不读取。测试使用合成记录、隔离内存存储和模拟后端，不访问用户数据或模型服务。

静态检查通过。103项客户端测试全部通过。Android ARM64 profile构建结果与安装检查见下方补记。

本轮没有采集真实药盒，也未新增未经审核的药物分类知识。现有药名词表仍为6个完整名称，无法声称全面识别药品。真实包装和多品牌国内手机测试仍待补充。

本轮只更新APP，无需部署服务器，尚未推送团队仓库。组员需要安装新版才能使用本轮入口。
