# 按键语音对话首版与验证（2026-11-02）

## 本轮完成的功能

语音入口不再是占位页。首版采用逐轮按键方式：先导入并解读报告→打开语音对话→主动允许麦克风→开始说话→结束并识别→核对/修改文字→确认发送→现有真实大模型回答→可选本机中文朗读。与文字页共享报告、焦点指标、消息历史、资料出处和安全提示，不创建另一套医学判断。

本机普通话识别采用Vosk小型中文模型0.22，模型约42MB压缩文件随APK提供；不调用Google语音服务、系统联网识别或第三方云端语音。录音只在内存中流式处理，不写文件、不上传。只有用户核对后确认的文字及现有脱敏报告上下文发送到已有解读服务。系统中文朗读仍只使用已安装的离线普通话音色。

## 界面和控制

- 首页、文字对话和设置均有入口；没有报告时明确引导先导入，不启动麦克风。
- 首次只请求麦克风权限，允许后要求再次主动点击开始，不会授权即录音。
- 每轮最多30秒，支持结束识别、取消录音、保留旧草稿和修改文字；识别结果不会自动发送。
- 模型回答后默认朗读，可关闭“回答后朗读”或随时停止；重新开始说话会先停止播放。
- 切换到文字页保留共享消息；退到后台、切页、销毁页面取消录音，迟到识别不污染草稿，后台返回的模型结果不自动播放。
- 权限拒绝、缺少音色、空音频、识别失败、模型失败保留文字入口；不把服务错误冒充成功回复。
- 撤回指标云端授权后禁止发送问题。药名和数字可能识别有误，必须人工核对。
- Vosk、中文模型和JNA采用Apache-2.0许可，许可与出处随包提供；语音页信息按钮可查看许可。

## 验证

客户端新增9项语音页面测试，总计146项通过，静态分析通过。覆盖无报告、权限拒绝/授权不自动录音、可编辑草稿与主动发送、迟到识别、后台迟到回复不朗读、错误保留草稿、无音色降级、打断朗读、语音/文字共享历史以及撤回云端授权、大字/键盘布局。

真实模拟器原生联测3项通过：系统TTS生成固定普通话“你好，请问今天的天气怎么样。”，真实离线模型返回“你好请问今天的天气怎么样”；静音PCM返回空结果；真实麦克风前台启动后取消，结果为空、资源释放后还能继续离线识别。使用合成音频，不读取用户报告或录音；测试生成的临时WAV已删除。

首次测试遇到模拟器SystemUI无响应弹窗，前台录音保护正确拒绝；随后模拟器自身HangDetector退出，不能算作APP通过。保留数据冷启动后重测通过，同时把录音改为非阻塞读取，停止/释放统一由后台工作线程完成，避免UI线程阻塞。没有移除“只允许前台主动录音”保护。

## 仍未完成

这是一轮一问的按键语音，不是连续实时双向音频会话。自动端点、连续轮次、声学回声消除、说话自动打断与跨设备适配仍待后续。当前支持的是点击开始说话来停止回答朗读。通用小模型未做医学专用词表训练或医学审核，真实人声、口音、噪声和多品牌麦克风识别率仍需验证；合成样本通过不代表临床可用。

后端沿用现有大模型，未修改服务器或新增密钥；无法联网时可本机听写及编辑，但模型回答需要连接学校服务器。

## 使用方法

1. 导入报告并查看解读。
2. 从首页“语音对话”，或文字提问页面的麦克风图标进入。
3. 点击“开始说话”。首次在系统弹窗允许后，返回再点击一次。
4. 说完点击“结束并识别”，核对或修改文字，尤其是药名和数字。
5. 点击“确认文字并发送”。回答会显示在页面中，“回答后朗读”可关闭；也可随时点击“停止朗读”。
6. 想换一个问题，可再次点击开始说话，当前播报会先停止。键盘图标可切回文字对话。

首次模型解压和加载可能稍久，之后复用本机模型。语音识别不需要网络，模型问答仍需要连接现有服务器。没有报告时不能发起基于报告的语音问答。
